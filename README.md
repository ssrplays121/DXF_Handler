# DXF Layer Explorer

A browser-based tool for exploring and analyzing DXF layer data extracted from CAD files.

## Features

- **Layer-based Organization**: View each DXF layer separately
- **Interactive Visualization**: Explore geometry with zoom, pan, and selection
- **Comprehensive Statistics**: Charts and analytics for entity distribution
- **Error Tracking**: View extraction errors and warnings per layer
- **Multiple Export Formats**: Export data as CSV, Excel, JSON, or images
- **Search & Filter**: Quickly find entities, layers, or properties
- **Responsive Design**: Works on desktop and mobile devices

## Prerequisites

- Modern web browser (Chrome 86+, Edge 86+, Firefox, Safari)
- DXF layer JSON files generated by `layering.py`

## Installation

1. Clone or download this repository
2. No additional installation required - open `index.html` in your browser
